# Jimmy Li Learning Hub

## Product truth

Jimmy Li Learning Hub is a personal portfolio and digital knowledge garden for a high-school student preparing for the 2027 GSAT. It brings together study planning, vocabulary practice, projects, research, course outcomes, subject notes, and reflections in one durable place.

## Primary audience

- Jimmy, using the study tools and adding material over time.
- Teachers, reviewers, and admissions readers scanning for evidence of curiosity, process, and growth.
- Classmates or visitors opening shared notes and project work.

## Core promise

Make an active learning process easy to understand: what Jimmy is studying, building, documenting, and improving.

## Content and IA to preserve

- Home
- GSAT countdown and study dashboard
- Daily study plan and vocabulary tools
- Projects and project detail
- High-school learning portfolio database
- About and contact links
- Existing anchors, sub-sites, PDFs, stored local data, and GitHub Pages deployment

## Voice

Clear, direct, curious, and personal. Use Traditional Chinese for primary UI copy, with short English labels only where they already aid orientation.

## Design principles

- Feel like a student-maintained editorial workspace, not a generic AI product landing page.
- Prefer a light paper-like canvas, near-black type, one brick-red accent, thin rules, and asymmetric editorial spacing.
- Use borders and whitespace before cards, glows, blur, gradients, or decorative effects.
- Keep motion quiet and functional. Respect reduced-motion settings.
- Keep controls usable and preserve every working feature.

## Technical constraints

- Static HTML, CSS, and JavaScript.
- No new runtime dependency.
- Preserve selectors and element IDs used by `assets/js/app.js`.
- Continue to work on GitHub Pages and on mobile.
